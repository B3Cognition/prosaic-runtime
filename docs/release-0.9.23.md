# Runtime 0.9.23 — bounded sub-agents

Role-aware API turns can call host-registered specialist aliases. Each child receives its own bounded projection, the task, and an optional schema-checked draft. The parent and children share provider and tool budgets, a deadline, and the parent's billing attribution. Each specialist uses the same resolved provider route and reviewed local read tools.

The host supplies a fenced journal, an accounting recorder, and current launch and result grants. The journal seals the route and frozen context for each child slot. Approved child observations enter the existing parent citation pipeline after delivery. Prepared turns that select a delegate use encoding v6 and frozen-input format v5. Ordinary turns retain their existing encodings.

Harness 0.9.17 adds authored workflow and conversation bindings. Core 0.5.0 and PostgreSQL recorder 0.3.0 remain compatible. See the [Runtime API setup](../README.md#bounded-sub-agents).
