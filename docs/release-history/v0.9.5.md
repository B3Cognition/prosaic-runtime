# prosaic-runtime 0.9.5 — Execution lifecycle and controlled tool failures

Adds host-generated HTTP correlation and cooperative synchronous execution draining. Accounting intent precedes dispatch; correlation IDs are not provider receipts or idempotency promises. Trusted callbacks may return `ToolFailure` only for a proven completed failure; journal replay returns that result without redispatch. Ordinary exceptions and lost acknowledgements retain uncertainty. No automatic interrupted-call retry or accounting identity/schema migration is introduced.
