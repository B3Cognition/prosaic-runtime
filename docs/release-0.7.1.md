# Prosaic Runtime 0.7.1

Exports pure execution-artifact and native-tool validation for in-memory
workflow admission. The public helpers share routing, effort and provider-control
checks with execution; acquisition inherits the final agent's effective route
and effort unless it explicitly requests matching values. Admission invokes no
model, callback or CLI probe.

Pins Prosaic 0.3.2 at `af7d90e178f61d53ba71bcc61c41c3ef7f941b4c`.
The PostgreSQL recorder remains 0.1.1 and its stored accounting contracts remain
compatible. Customer charging and authorization remain application-owned.

Local qualification passed 495 tests with one opt-in interpreter test skipped,
wheel/source builds and clean installed native-tool execution with synthetic
loopback providers. Release requires the final commit's Linux AMD64/ARM64 and
macOS Python 3.11/3.12/3.13 matrix, operational sandbox gates and PostgreSQL 16/18
recorder checks. The published verification asset records native results and
checksums of downloaded release artifacts.

Install through the immutable GitHub tag or release wheel/source assets. This
release is distributed through GitHub rather than npm or PyPI. No paid inference
is part of qualification.
